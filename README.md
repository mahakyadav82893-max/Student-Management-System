# Student Management System

A simple Student Management System developed in C++. This project allows users to enter and display basic student information such as roll number, name, and marks.

## Features

- Add student details
- Display student information
- Supports multiple students
- Simple and easy-to-use console interface

## Technologies Used

- C++
- Object-Oriented Programming
- VS Code

## Project Structure

```text
Student-Management-System/
├── main.cpp
└── README.md
```

## How to Run

Compile the program using:

```bash
g++ main.cpp -o student
```

Then run:

```bash
.\student.exe
```
